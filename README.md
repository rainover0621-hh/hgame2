# 한문 출정기 (漢文遊戲)

1년 동안 배운 한문을 복습하는 세로형 액션 퀴즈 게임입니다.
장수가 되어 화살을 피하며 적병을 베고, 길을 막는 적장과 대장은 검기로 체력을 모두 깎은 뒤 한문 문답으로 물리칩니다.

- 게임: [index.html](index.html)
- **선생님용 배포 (단원 선택 · QR 만들기)**: [teacher.html](teacher.html) → https://rainover0621-hh.github.io/hgame2/teacher.html
- 테스트용 (각 장·대장부터 바로 시작, 무적 모드): [test.html](test.html)

파일 하나로 실행됩니다. 브라우저로 `index.html`을 열면 바로 시작돼요. 배경음과 효과음도 파일 안에 들어 있어요.

## 구성

- **3개의 장**: 一章 국경 산길 · 二章 강가 진지 · 三章 적의 성채 (모두 15陣)
- **화살**: 일반 · 겨냥 · 유도 · 불화살 · 부채꼴 연사 · 측면 · 독화살 · 신기전 · 화살비
- **적**: 보병 · 궁병 · 기병, 적장(체력 10·문제 1), 장 대장(체력 10·문제 2), 최종 대장(체력 20·문제 3)
- **아이템**: 藥 약초 · 蔘 인삼 · 盾 방패 · 書 병법서 · 劍 보검 · 鼓 북 · 速 질풍
- **출제 범위**: 교과서 1~8과 어휘 · 성어 62개, 독음 · 뜻풀이 124문제 (선생님 배포 페이지에서 과 선택) — [문제 목록](docs/문제-목록.md)
- 장 대장 문제를 맞힐 때마다 승전 보상으로 기력 +15
- 결과 화면의 오답 노트와 **틀린 문제 다시 풀기**(시간 제한·기력 감소 없음)로 복습

## 배포 (QR)

1. https://rainover0621-hh.github.io/hgame2/teacher.html 에서 출제할 단원을 고릅니다.
2. 만들어진 QR을 화면에 띄우거나 **QR 안내문 인쇄**로 나눠 줍니다.
3. 학생 화면에서는 단원을 바꿀 수 없고, 학년·반·번호·이름을 적어야 출정할 수 있습니다.

## 문제 추가·수정

`index.html` 안의 `QUESTIONS` 배열에 한 줄씩 추가합니다. 보기(`o`)는 첫 번째가 정답이며 화면에서는 섞여 나옵니다.

```js
{u:'7', c:'고사성어', d:1, q:'뜻은?', h:'白眉', o:['정답','오답1','오답2','오답3'], e:'해설'},
```

- `u` 과 · `c` 분류 · `d` 난이도(1~3) · `q` 질문 · `h` 크게 보여 줄 낱말 · `e` 해설

난이도·체력 등은 파일 위쪽 설정값(`HARD`, `CHAPTERS`, `ARROWS`, `FOE_HP`, `BOSS_HP`, `FINAL_BOSS_HP`, `FIRE_RATES`, `TRAVEL_X`, `EASE_FROM`, `EASE_X`)에서 바꿀 수 있습니다.
