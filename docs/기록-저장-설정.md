# 학생 기록을 구글 시트로 받기

학생이 게임을 끝낼 때마다 **학년·반·번호·이름, 결과, 점수, 정답률, 틀린 문제**가 선생님의 구글 시트에 한 줄씩 쌓입니다.
처음 한 번만 설정하면 되고 5분쯤 걸립니다.

```
학생: 게임 플레이 (GitHub Pages 주소)
  → 끝나면 결과를 자동 전송
  → 선생님 구글 시트에 한 줄씩 저장
  → 선생님: 시트에서 확인 · 정렬 · 필터
```

---

## 1. 시트 만들기

1. 구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 정합니다 (예: `한문 출정기 기록 2026`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있던 코드를 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](../apps-script/Code.gs) 내용을 그대로 붙여 넣은 뒤 **저장(💾)** 합니다.
4. (선택) 위쪽 함수 목록에서 `시트_준비`를 고르고 **실행**하면 시트 4개가 미리 만들어집니다.
   처음 실행할 때 권한 확인 창이 뜨면 **본인 계정 선택 → 고급 → (안전하지 않은 페이지로) 이동 → 허용**을 누릅니다. 본인이 만든 코드라서 나오는 안내입니다.

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. 아래처럼 설정합니다.
   - **다음 사용자 인증 정보로 실행**: `나`
   - **액세스 권한이 있는 사용자**: `모든 사용자` (영문 화면은 *Anyone*)
4. **배포**를 누르고, 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. 그 주소를 브라우저 새 탭에 붙여 넣어 열었을 때 `한문 출정기 기록을 받을 준비가 되었습니다.`가 보이면 성공입니다.

## 3. 게임에 주소 넣기

복사한 웹 앱 주소를 Claude에게 알려 주면 게임에 넣어 GitHub에 올려 드립니다.
직접 하실 때는 `index.html`에서 아래 한 줄을 찾아 따옴표 안에 주소를 넣고 저장해 올리면 됩니다.

```js
const RECORD_URL = '';
```

이제 학생 첫 화면에서 **학년·반·번호·이름**을 모두 적어야 출정할 수 있고, 게임이 끝나면 결과 화면에
`3학년 2반 5번 홍길동 · 선생님께 기록을 보냈어요.`가 표시됩니다.

## 학교 계정과 개인 계정

**학교 구글 계정(Workspace for Education)을 기본으로** 쓰면 됩니다. 다만 학교 관리자 설정에 따라 2단계의 **`모든 사용자`가 목록에 없을 수 있습니다.**
이때는 `○○학교 내 모든 사용자`만 고를 수 있는데, 이렇게 배포하면 학생이 학교 계정으로 로그인하지 않은 기기나 브라우저에서는 기록이 전송되지 않습니다.

| 상황 | 방법 |
|---|---|
| 학교 계정에서 `모든 사용자`를 고를 수 있음 | 그대로 학교 계정으로 진행 (권장) |
| 학교 계정에 `모든 사용자`가 없음 | **개인 구글 계정**으로 1~3단계를 똑같이 진행 |
| 개인 계정으로 만들었지만 학교 계정으로 보고 싶음 | 시트 오른쪽 위 **공유**에서 학교 계정을 추가 (뷰어 또는 편집자) |

개인 계정으로 만들어도 학생은 아무 계정 없이 기록을 보낼 수 있고, 선생님은 공유받은 학교 계정으로 시트를 볼 수 있습니다.

## 시트에서 보이는 것

| 시트 | 내용 |
|---|---|
| **기록** | 한 판마다 한 줄: 받은 시각, 학년·반·번호·이름, 결과(대첩·승전·신승·참승·패퇴), 완주 여부, 점수, 맞힌 수/푼 수, 정답률, 도달한 陣, 물리친 적, 최고 연속 정답, 출제 범위, 플레이 시간, 틀린 문제 목록 |
| **오답** | 틀린 문제 하나마다 한 줄 (누가 어떤 문제를 틀렸는지) |
| **요약** | 학생별 플레이 횟수, 완주 횟수, 최고 점수, 평균 정답률, 마지막 플레이 시각 (자동 계산) |
| **많이 틀린 문제** | 반 전체가 많이 틀린 문제 순위 (자동 계산) — 수업 복습 자료로 활용 |

시트의 **데이터 → 필터 만들기**를 쓰면 반별·날짜별로 골라 볼 수 있습니다.

## 게임 안의 '오늘의 순위'

시트를 연결하면 학생들이 게임 첫 화면(**오늘의 순위 · 내 기록**)이나 결과 화면(**오늘의 순위 보기**)에서
오늘 기록된 학생별 최고 점수 순위를 볼 수 있습니다. **전체 / 우리 반**으로 나눠 볼 수 있습니다.

- 이름은 가운데 글자를 가려서 보여 줍니다 (예: 홍길동 → 홍*동). 학년·반·번호는 그대로 보입니다.
- 순위는 시트의 **오늘 날짜** 기록만 씁니다. 날짜는 시트의 시간대(파일 → 설정 → 시간대, 보통 서울)를 따릅니다.
- 시트를 연결하기 전이거나 인터넷이 안 될 때는 **그 기기에서 오늘 한 기록**으로 순위를 보여 줍니다 (태블릿 한 대를 여럿이 쓸 때 유용).

## 알아 두기

- 이미 배포한 뒤에 `Code.gs`를 새 버전으로 바꿨다면(예: 오늘의 순위 기능 추가) 아래 방법으로 **새 버전 배포**를 해야 순위가 나옵니다.
- **코드를 고친 뒤에는** 배포 → **배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 웹 앱 주소는 바뀌지 않습니다. (새 배포를 만들면 주소가 바뀝니다.)
- **본인 확인이 없습니다.** 학생이 다른 이름을 적어도 막을 수 없으므로, 성적 반영보다는 수업 중 연습·복습 확인용으로 쓰는 것을 권합니다.
- 웹 앱 주소는 게임 파일 안에 들어가므로, 누군가 일부러 가짜 기록을 보낼 수는 있습니다. 이상한 줄은 시트에서 지우면 됩니다.
- 인터넷이 끊겨 전송에 실패한 기록은 학생 기기에 보관했다가 다음에 게임을 열 때 자동으로 다시 보냅니다.
- **테스트 페이지(`test.html`)는 기록을 보내지 않습니다.**
- Claude 화면의 미리보기 링크(claude.ai)에서는 보안 설정 때문에 기록이 전송되지 않습니다. 학생에게는 GitHub Pages 주소를 안내해 주세요.
- 학생 개인정보(이름)를 다루므로 학교의 개인정보 처리 방침에 맞게 시트 공유 범위를 관리해 주세요.
