# 다른 학교 · 다른 반 선생님이 쓰는 법

게임 주소는 모두 같이 씁니다. 선생님마다 **자기 구글 시트**를 하나 만들고, 배포 페이지에서 그 시트 주소를 넣어 **자기 학교용 링크 · QR**을 만들면 됩니다.
코드를 고치거나 GitHub에 올릴 일은 없습니다.

```
같은 게임 주소 + ?r=(내 시트) ──▶ 우리 학교 학생 기록은 내 시트로
                 ?u=(단원)    ──▶ 내가 고른 단원만 출제
```

## 1. 내 기록 시트 만들기 (5분, 처음 한 번)

[학생 기록 받기 설정](기록-저장-설정.md)의 1~3단계를 그대로 하면 됩니다.

1. 내 구글 드라이브에 새 스프레드시트를 만들고 **확장 프로그램 → Apps Script**에 [`apps-script/Code.gs`](../apps-script/Code.gs)를 붙여 넣습니다.
2. `시트_준비`를 실행해 시트 5개를 만들고, **명렬** 탭 A~D열에 우리 학교 학생 명단(학년 · 반 · 번호 · 이름)을 붙여 넣습니다.
3. **배포 → 새 배포 → 웹 앱** (실행: 나, 액세스: 모든 사용자) 후 **웹 앱 주소(…/exec)**를 복사합니다.
   학교 계정에서 `모든 사용자`가 없으면 개인 구글 계정으로 만들고 학교 계정에 공유합니다.

## 2. 우리 학교용 링크 · QR 만들기

1. 선생님용 배포 페이지를 엽니다: https://rainover0621-hh.github.io/hgame2/teacher.html
2. **학생 기록 받을 곳 → 내 구글 시트로 받기**를 고르고 복사한 웹 앱 주소를 붙여 넣습니다.
   오른쪽에 `기록: 내 구글 시트로 받습니다`가 보이면 됩니다.
3. **출제 단원**을 고릅니다.
4. 만들어진 QR을 화면에 띄우거나 **QR 안내문 인쇄**, 또는 **주소 복사**로 나눠 줍니다.

배포 페이지는 이 기기에 입력값을 기억하므로, 다음에는 단원만 바꿔 새 QR을 만들면 됩니다.

## 3. 확인하기

**학생 화면 열기**로 한 판을 끝까지 해 보고, 내 시트 **기록** 탭에 한 줄이 생기는지 봅니다. (확인 후 그 줄은 지워도 됩니다.)

## 알아 두기

- **꼭 배포 페이지에서 만든 링크 · QR을 쓰세요.** 아무것도 붙지 않은 기본 주소(`…/hgame2/`)로 들어오면 기록이 이 게임을 만든 선생님의 시트로 갑니다.
- 기록을 전혀 받지 않으려면 배포 페이지에서 **기록 받지 않기**를 고르세요. 학생의 '나의 기록'은 학생 기기 안에만 남습니다.
- 학생 화면의 **우리 반 순위**는 링크에 넣은 시트의 기록으로 계산됩니다. 학교마다 따로 보입니다.
- 학생이 링크 주소를 직접 고치면 단원이나 기록 시트가 바뀔 수 있습니다. 수업용 연습 · 복습 도구로 쓰는 것을 권합니다.
- 문제(교과서 1~8과)를 학교 교과서에 맞게 바꾸려면 게임 파일을 복사해 따로 올려야 합니다. 필요하면 제작 선생님께 문의하세요.
