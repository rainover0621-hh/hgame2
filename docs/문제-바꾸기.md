# 내 문제로 출제하기 (구글 시트)

게임 문제를 **내 기록 시트의 `문제` 탭**에서 고칩니다. 코드나 GitHub는 몰라도 됩니다.
고친 내용은 학생이 게임을 다시 열 때 바로 반영되고, QR · 학생 링크는 그대로 씁니다.

- `문제` 탭이 **비어 있으면** 게임에 들어 있는 기본 문제(교과서 1~8과, 251문제)로 출제합니다.
- `문제` 탭에 **한 줄이라도 있으면** 그 문제만으로 출제합니다.

## 준비 (처음 한 번)

1. 내 기록 시트에서 **확장 프로그램 → Apps Script**를 열고, 코드를 최신 [`apps-script/Code.gs`](../apps-script/Code.gs)로 바꿔 붙여 넣고 저장합니다.
2. 함수 목록에서 `시트_준비`를 **실행**하면 `문제` 탭이 생깁니다.
3. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. (웹 앱 주소는 바뀌지 않습니다)

## 기본 문제를 불러와서 고치기 (추천)

1. [문제 템플릿 내려받기](../share/문제-템플릿.csv) — 지금 게임의 문제 251개가 들어 있습니다. (GitHub 화면에서 **Download raw file** 버튼)
2. 시트의 **`문제` 탭**을 연 상태에서 **파일 → 가져오기 → 업로드**로 내려받은 파일을 올리고, **가져오기 위치: 현재 시트 바꾸기**를 고릅니다.
3. 필요 없는 문제는 줄을 지우고, 고칠 문제는 칸을 고치고, 새 문제는 아래에 줄을 추가합니다.

## 칸 설명

| 칸 | 적는 것 | 예 |
|---|---|---|
| 과 | 단원 번호 (배포 페이지에서 이 번호로 단원을 고름) | `5` 또는 `5과` |
| 분류 | 문제 카드에 보이는 분류 | `한자성어` |
| 난이도(1~3) | 1 쉬움 · 2 보통 · 3 어려움. 높을수록 정답 점수와 오답 피해가 큼 | `1` |
| 질문 | **필수** | `이 성어의 뜻은?` |
| 크게 보일 글자 | 문제 가운데 크게 보여 줄 한자 · 문장 (없어도 됨) | `一石二鳥` |
| 정답 | **필수** | `한 가지 일로 두 가지 이익을 얻음` |
| 오답1~3 | **오답1은 필수**, 2~3은 없어도 됨 (보기는 게임에서 섞임) | |
| 해설 | 답을 고른 뒤 보여 줄 설명 (없어도 됨) | |
| 유형 | `독음` · `뜻` · `어려움` 중 하나 (비우면 질문을 보고 자동) | `뜻` |
| 낱말 | 같은 낱말 문제끼리 묶는 이름. 한 판에 같은 낱말은 한 번만 나옴 (비우면 '크게 보일 글자') | `一石二鳥` |

- `질문` · `정답` · `오답1`이 비어 있는 줄은 무시합니다.
- 한 판은 19문제입니다. 고른 단원의 **낱말 수**가 19개보다 적으면 그만큼 짧은 판이 됩니다.
- `유형`이 `어려움`인 문제는 낱말마다 40% 확률로 나옵니다 (나머지는 `독음` · `뜻` 문제).

## 확인하기

1. 배포 페이지(https://rainover0621-hh.github.io/hgame2/teacher.html)에서 **내 구글 시트로 받기**에 웹 앱 주소를 넣으면
   `문제 탭: ○문제 (5과 · 6과 …) → 이 문제로 출제합니다`가 보이고, 단원 칸이 내 문제의 과로 바뀝니다.
2. 옆의 **내 문제로 테스트**를 누르면 테스트 페이지에서 내 문제로 바로 해 볼 수 있습니다 (기록은 보내지 않음).
3. 단원을 고르고 QR을 다시 만듭니다. (단원을 바꾸지 않았다면 기존 QR을 그대로 써도 됩니다)

## 알아 두기

- 학생 기기는 마지막으로 받은 문제를 기억해 두었다가, 인터넷이 느리거나 끊기면 그 문제로 출제합니다.
- 시트의 `문제` 탭을 모두 지우면 다시 기본 문제로 돌아갑니다.
- claude.ai 미리보기 화면에서는 보안 설정 때문에 시트 문제를 불러오지 못합니다. GitHub Pages 주소(배포 페이지 · 테스트 페이지)에서 확인하세요.
